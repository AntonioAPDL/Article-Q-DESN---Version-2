# PriceFM R137 four-region pure-QDESN pilot

## Decision and scope

R137 tests whether the successful R135 pure-QDESN strategy transfers beyond BG, HR, and DK_1
before any all-region launch. It evaluates two regions where the frozen R98 QDESN authority was
weak relative to the local PriceFM reference (SK and HU) and two where it was strong (IT_NORD
and EE). These labels select contrasting development cases; they do not enter any R137 model
choice. R137 cannot promote a model, mutate the registry or article, or authorize all regions.

Four isolated, resumable campaigns run as two 15-physical-core controllers on each host:

- Jerez: SK and IT_NORD;
- Muscat: HU and EE.

Each controller receives an explicit, disjoint CPU list. BLAS, OpenMP, NumExpr, and R data-table
thread counts are one, so one worker represents one physical core. Two physical cores remain
outside the PriceFM pools on each 32-core host. There is deliberately no campaign-size cap. A
20-GiB free-space floor remains only as protection against filesystem exhaustion.

## Scientific workflow

Each region independently follows the audited R135 strategy:

1. Build four immutable training-only banks: target-only, graph mean, graph mean plus standard
   deviation, and neighbor exogenous inputs. Future target prices are never inputs.
2. Score at least 640 admissible balanced candidates with Normal Ridge on three forward inner
   splits of the first official training window. The R98 architecture, all inherited R123
   basins, and the exact common R135 basin are protected controls, not presumed winners.
3. Retain the best 30 Ridge structures plus protected controls. Fit Normal RHS VB for three
   dimension-aware tau0 magnitudes, additionally retaining the R98 tau0 for its control.
4. Advance the best two complete structure/tau0 groups to seven nested independent AL-RHS VB
   fits. Choose the regional winner by mean AQL across all three inner splits, with no official
   forecast outcome used for selection.
5. Freeze that specification and refit Normal RHS plus all seven AL levels separately on the
   three official folds. Generate 500 recursive 96-step paths per origin and report the complete
   fold cohort against frozen R98 QDESN and PriceFM references.

Between origins, observed history is restored (teacher forcing). Within each 96-step forecast,
unknown price lags are recursively generated by the matching Normal RHS path. Released realized
exogenous inputs define the same retrospective conditional experiment used by the frozen
comparison. The primary quantile operator is `cdf_pool_clipped`; alternatives remain diagnostics.

## Search and R135 transfer

The broad design spans output lags 32--2880, exogenous lags 0--672, depth 2--6, readout dimension
up to 1537, alpha 0.05--0.90, rho 0.40--0.99, input scale 0.01--0.50, recurrent sparsity
0.01--0.20, fan-in 8--256, and several tapered width profiles. The reservoir seed is fixed.

The exact R135 basin is injected under target-only and graph-mean-plus-SD features and under both
coverage and balanced sparse input wiring: output lag 2016, exogenous lag 4, widths 192/192,
alpha 0.15, rho 0.55, input scale 0.01, fan-in 8, recurrent sparsity 0.05, and inter-layer gain
1.0. R135 showed that this basin can be excellent overall but is not uniformly best by fold, so
the broad search remains essential.

## Numerical and provenance contract

All AL fits use the project-pinned R 4.6 runtime and public CRAN `exdqlm` 1.1.1 adapter, fixed
zero prior centers, and warm starts
only as initial variational states. The AL budget is exactly 300 iterations. A formally converged
fit passes directly; a finite capped fit passes only if the independent same-state fixed-point
certificate meets every frozen tolerance. An uncertified fit blocks its descendants. There is no
automatic iteration extension and no 300-versus-1000 selection experiment.

The execution source, dependency HEAD, contracts, raw input, training banks, package manifest,
and completion evidence are hashed. Runtime outputs remain excluded from Git. Only the dedicated
R137 task branch is committed and pushed; authoritative main and Overleaf are untouched.

## Interpretation gate

R137 is complete only when all twelve region-fold evaluations exist and all upstream fits are
certified. The closeout must compare aggregate and fold-level AQL, horizon behavior, calibration,
crossing, selection stability, and failures with the frozen R98 QDESN and PriceFM references.
The result decides whether an all-region campaign is worth proposing; it does not itself promote
or integrate anything.
