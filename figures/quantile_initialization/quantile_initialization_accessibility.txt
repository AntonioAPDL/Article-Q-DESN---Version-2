Sequential initialization for a quantile grid containing the median. A preliminary Gaussian ridge regression supplies starting values for Gaussian regularized-horseshoe variational Bayes, which initializes the median asymmetric-Laplace regression. Independent AL fits proceed outward toward each tail. Each completed AL fit initializes exAL at its own probability level. Complete independent grids initialize matching MQ-DESN variational fits only in the multiquantile simulation and GloFAS application; PriceFM uses independent AL/exAL variational fits only. The lower-left relation shows VB initializing MCMC for the same statistical model in the multiquantile simulation. GloFAS and PriceFM use variational inference. The independent single-quantile validation follows a separate procedure. Solid arrows indicate transfers of starting values, not prior calibration or specification selection. The dashed lower-right arrow denotes comparison of fitted candidate specifications using a prespecified development criterion. Any Gaussian-derived prior calibration is separate from these transfers and fixed before the subsequent comparison.
