# MQ typed-v2 generated workflow

## Scope and status

This opt-in scaffold tests the route from a worker through typed numerical
evidence, independent acceptance, lossless decoding, and scoring. It does not
admit a reconstruction campaign, extend the genuine one-unit MQ qualification,
or replace the canonical SQLite controller. Its only executable route accepts
generated fixtures. No historical fit, observed simulation fixture, runtime
cache, scoring truth, article asset, or protected source is read or changed.

The original v1 worker, DKW receipts, block codec, scorer, controller, source
manifest and source guard are unchanged. New implementation files are under
`scripts/`, rather than adding an unapproved application implementation to the
original source guard's protected directories. A separate exact manifest pins
the new files and unchanged dependencies. It additionally checks all 27 v1
files without broadening their authorization.

## Executed generated route

1. `scripts/run_integrated_quantile_forecast_v2.R` accepts only
   `--generated-fixture-output ABSOLUTE_FRESH_DIRECTORY`. Its request freezes
   the generated producer identity, model, probability/horizon grid and expected
   members before path evaluation.
2. `mqw2_run_unit()` uses an explicitly supplied generated kernel provider.
   Training paths 1–65,536 determine candidates and the two-half diagnostic.
   Only after those candidates are frozen are validation paths
   65,537–327,680 evaluated. The unchanged streaming certificate uses the
   three fixed looks, fixed alpha spending and original precision rules.
3. The unchanged `iqr2` module compacts sufficient statistics and packs a
   lossless reference block. The generated packet contains that block, an
   explicit primitive JSON numerical view, and an exact two-artifact manifest.
   It retains neither a full validation matrix nor a claim of authenticated
   independent native stream generation.
4. `scripts/forecast_transition_typed_v2.py` independently recomputes the
   candidate endpoints, bounded-data variance, empirical-Bernstein radii,
   strict quantile inequalities and split diagnostic. It checks complete
   predeclared member membership and identity. Producer PASS labels are ignored.
5. A separate native R process decodes the actual compact block, checks all
   `iqr2` hashes and members, and compares its complete numerical/identity view
   with the JSON. A passing sidecar cannot conceal different block values.
   The result is a **generated-only, stateless acceptance**, not a canonical
   ledger transition. No source or host authentication is inferred from hashes.
6. `mqw2_score_accepted()` rechecks packet bytes, acceptance bindings and every
   member before examining the supplied generated oracle. The score uses the
   unchanged expected check-loss calculation and unnormalized trapezoidal
   weights. A v2 receipt is never relabelled as a v1 DKW receipt.

The end-to-end test runs this actual CLI chain. Two degenerate iid generated
conditional-CDF examples stop at different permitted looks, exercising lossless
heterogeneous member evidence. These are mathematical test fixtures, not new
scientific qualification or source-authenticated IID demonstrations. Endpoint
atoms, flat grids, rejection before oracle access, malformed precision evidence,
changed identities, mismatched block/sidecar values and legacy v1 rejection are
tested separately. No new random seed or response distribution is selected.
The independent Python tests additionally cover all 420 endpoints of the
30-horizon, seven-level geometry. The generated worker example is smaller;
neither example is a new native numerical qualification.

## Numerical meaning

For M fixed scalar CDF endpoints and validation size n, the radius is

`sqrt(2 s² log(4M/alpha_look)/n) + 7 log(4M/alpha_look)/(3(n−1))`.

Each candidate q uses delta=max(0.01,0.01|q|). Acceptance requires
`UCB F(q−delta) < p` and `LCB F(q+delta) >= p`. The three look allocations
sum to 0.05 for **one fixed original parameter draw and observed origin**.
The statement is not simultaneous over all campaign members. The deterministic
test examples do not waive finite-sample bounds or authenticate a source.

The scorer exposes the deterministic Lipschitz propagation
`2 sum_k w_k max(p_k,1−p_k) delta_k` as a bound on the origin–horizon score
error on the joint endpoint-confidence event. This is not a newly approved
publication tolerance or a confidence interval across parameter draws. Deciding
whether the original quantile precision is adequate for final contrasts remains
an explicit production gate.

## Unresolved production interfaces

Calling any CLI without generated arguments reports
`MQ_PRODUCTION_NOT_ADMITTED`; no `run` or launch route exists. The following
must be resolved prospectively, without reusing generated acceptance as proof:

- Authenticate the native draw inventory, weights and independent-MQ coupling;
  do not choose a convenient historical subset or thin posterior columns.
- Freeze the confidence statement across the full campaign and an acceptable
  score/contrast precision. The one-unit 0.05 policy is not a campaign policy.
- Freeze and price production retention. The list-based `iqr2` codec and 8 MiB
  generated block cap are reference implementations, not a full-scale storage
  contract or cost estimate.
- Requalify the exact production worker source and native path adapter under
  MP01. Genuine evidence for the frozen source562 unit remains valid for its
  own source and scope; this new route cannot silently inherit it.
- Obtain fresh host/resource and complete campaign cost admission. Neither
  source-byte checks nor numerical bounds permit automatic queuing.
- Define a versioned canonical ledger authorization/claim/accept protocol,
  including official task, source, grant, expiry, membership, cumulative output
  and producer bindings. This scaffold deliberately cannot mutate that ledger.

Until these interfaces are frozen, connecting authentic inputs or adding an
actual dispatch route would bypass an unresolved gate. B04 is therefore a
tested generated wiring scaffold, **not a completed production rollout**.
