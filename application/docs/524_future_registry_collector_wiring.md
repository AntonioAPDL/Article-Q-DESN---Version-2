# Future append-only registry and collector route

This is a design, not an active collector change. The current three diagnoses
are failed diagnostics and the staged consumer is synthetic-only. Neither may
resolve a production task to accepted, change a regional source class or release
dependants. Original failed terminals, certificates and task seals remain
authoritative and immutable.

Any future real pilot needs a new append-only packet binding the original task,
posterior target, exact design/moment/source hashes, new implementation/runtime,
initializer provenance and complete cumulative-update/resource ledger. Distinguish
full stock checkpoint factors from conditional reconstruction of missing factors.
The old failed packet must remain linked, not overwritten or relabeled.

Acceptance remains finite AND(formal OR independent). Only the independent
branch requires all seven original named limits plus both RHS reconstructions;
do not silently change the OR into an AND. Prior, response/design units and
objective constants must remain part of the checked target-equivalence proof.

A separately reviewed source route may then create a new effective-fit packet
with an explicit resolution-registry seal. Downstream parent/task identities
must bind that packet's digest. A diagnostic path's existence, a generic truthy
repair flag or a synthetic convergence result is never sufficient. The current
R141 loader path and R146 global source-qualified regional collector require
explicit new producer/consumer integration; a toy branch cannot masquerade as
either historical source.

The collector must continue checking the complete three-fold/four-operator
surface and all exposed/nonconfirmatory labels. A training-only fallback is a
new model requiring its entire frozen quantile/fold confirmation, rather than
mixing one repaired fold with another candidate. Negative integration tests must
reject toy-origin packets, stale sources, wrong target/units/prior, partial
quantiles, mixed folds, missing budget history and diagnostic-only records.

No such real pilot is currently admitted, and no active registry, loader,
controller or collector source has been changed.
