# Genuine native source-regression route: qualification, not production

The generated-only candidate APIs remain unchanged. A distinct external
`mq_native_source_replay_v1` purpose is required by
`scripts/qualify_mq_native_composed.R`; help is safe, and no execution occurs
without exact external file/hash/`--execute` arguments. This source provides
no grant, retained build, runtime enrollment, actor or production permission.

The new exact source closure is `mqns_required_sources(native_paths)` in the
purpose's source pins plus clean committed tree and remote readback. It does
not extend `mqa_required_sources`. The retained observed-prefix derivation is
authenticated against the immutable **old producer** purpose/reducer/Git
closure separately. The original design/fixture is never deserialized.

The root coordinator supplies a separately bounded retained-build receipt,
three DLLs, complete toolchain/header/source hashes and runtime inventory.
The numerical purpose also pins the build's independent final inactive-unit
receipt: successful stop-post linkage, source/build-purpose identity and the
exact retained build-receipt output must agree. The external gate binds that
terminal receipt as well as the build itself.
A fresh external gate binds nonce, unit, source/tree, build, runtime inventory,
prepared manifest, original unit, optional reader permission, limits and
expiry. The supervisor must supply matching gate/purpose/unit environment
bindings. Native affinity/limits/TERM/KILL process-group proof is checked;
contexts remain current-process, live-expiry, immutable and purpose-bound.

Explicit LOAD_ONLY enrollment first loads retained DLLs but rejects numerical
methods and authentic data. Runtime matching includes actual DLL mappings.
Both inventory enrollment and the numerical actor source the same ten native
definition files and perform a deterministic QR/Cholesky warmup before runtime
matching, so lazy LAPACK mappings cannot appear only after enrollment.
Only after source/build/gate/runtime/preparation-metadata checks can the new
numerical handle read the granted retained prefix. Every global production,
refit, scoring, article and C ABI approval flag remains false.
Fresh ignored output ownership and failure/progress writers precede all
authentic numerical deserialization.

The replay preserves one original AL parameter/origin and scientific RNG
namespace, 30 horizons and seven levels, 65,536 training paths, at most 262,144
validation paths, three declared looks, total alpha 0.05, the original
numerical tolerances and 128-ID blocks.
The original 14 training sentinels precede candidate freeze; the final two are
deferred until freeze/split success. A NEW sealed context/handle authorizes
validation only after verifying its source/purpose-bound candidate commitment.
The original certificate update order and fixed-look alpha policy remain.
After freeze, the two existing deferred sentinels also compare individual
native CDF values with the unchanged reference at all frozen endpoints. These
parity values do not update the certificate or select candidates.

An optional explicit numerical-reference reader role permits the authenticated
old 125,829,790-byte training-array artifact only after its complete manifest,
schema, old accepted receipt/terminal and unit identities are checked. It is
not treated as a model/parameter or truth file. Without that role the driver
compares new training blocks with the unchanged 128-path reference generator.
All paths/ordered kernels are compared pointwise; declared scalar sentinels
also check states/raw grids/uniform bits. Output retains compact parity,
coherence, candidates and CDF statistics rather than new full training arrays.

The new driver preserves REVIEW/failure evidence, rechecks source/build/runtime
and candidate bytes at closure, and requires separate native administrative
terminal accounting. Replaying an old namespace is not novel statistical
validation. Passing this one unit cannot qualify the native catalog, all
likelihoods, a full campaign or article promotion. Representative stress,
canonical production wiring, confidence/score policy and full cost admission
remain later gates.
