# Phase162 legacy-output cleanup

The cleanup protects every directory used by the current article and independent confirmation chain. It removes only large per-origin prediction payloads from the superseded Phase135 matched-spec screen and PDF trace packets from the closed Phase136/140 sampler-sensitivity directions. Compact CSV summaries, registries, assessments, provenance, and manifests remain.

Every selected file is hashed before deletion. The cleanup artifact records its original path, byte size, SHA-256 hash, phase, rationale, and verified deletion status. Historical manifests are preserved as pre-cleanup records rather than rewritten.
