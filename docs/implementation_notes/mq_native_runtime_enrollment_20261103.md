# Metadata-only enrollment before the authentic native replay

`scripts/enroll_mq_native_runtime.R` has a separate external purpose for
software inventory, not numerical qualification. It authenticates the clean
published source and the retained build, including its independently closed
terminal record. It then loads only the verified public registered libraries,
sources the same native function definitions as the replay, and performs the
same deterministic QR/cholesky startup before recording runtime file hashes.

This resolves the initial loading/inventory dependency without a fake numeric
execution gate or a generated label on authentic data. It creates no numerical
backend handle and reads no scientific parameters, histories, designs or truth.
Installed R SDK/package metadata and code are software inputs, not model data.
The exact three known nonexecuting SSSD caches retain their explicit observation
role; no code library is exempted from byte equality.

The metadata purpose fixes CPU27, CPU120 seconds, TERM119/KILL1,2GiB address
space and64MiB output. Actual native timeout/process-group/resource checks,
fresh private outputs and full source/build rechecks are required. Output is a
runtime CSV, process maps and metadata receipt. The coordinator independently
closes its native time and verifies output/source identities before issuing
a different purpose for a real numerical replay. The latter still reloads
and checks the libraries and its actual runtime before any prepared input read.

Generated tests exercise metadata-only scope, permission, resource and CLI
rejections. They neither load an actual library nor create an execution grant.
