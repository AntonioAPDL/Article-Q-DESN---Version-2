# Final unified Q--DESN manuscript revision

Date: 2026-09-09

Scope: article presentation, notation, exposition, figure rendering, and reproducibility checks

Scientific authority at the start of the revision: `a51d5ea1dbaa9b32571160f77b5f11ec22f45195`

## Purpose

This revision reduces avoidable formalism and repetition while preserving the
scientific results already accepted for the independent validation, joint
validation, GloFAS, and PriceFM analyses. It also gives the independent and
joint validation figures a common graphical language. No model was refit, no
score was recomputed, and no numerical result was selected or replaced.

The implementation follows the detailed, ignored planning record at
`local_trackers/manuscript_revision_20260908/final_implementation_plan_and_audit.md`.
That record freezes the scientific inputs, identifies the protected claims,
and specifies the validation gates used below.

## Implemented changes

### Main article and supplement

- Removed unused theorem, algorithm, subcaption, and TikZ declarations from
  the main article.
- Standardized probability levels as `p_k`, the number of fitted levels as
  `K`, posterior draws as `b`, quantile-specific intercepts as
  `\beta_{0k}`, and the exAL positive-shift coefficient as
  `D_p(\gamma)`.
- Retained the integrated check-loss definition of CRPS and expressed the
  finite-grid approximation directly over the covered probability range.
- Added short left-hand descriptors to the principal multi-line displays.
- Consolidated repeated complete-data posterior expressions in the supplement
  into one generic augmented target with explicit model-specific
  specializations.
- Removed one-use display labels and several unnecessary named sets while
  preserving labels that are cited later.
- Condensed repeated derivations and redirected readers to the single location
  where each calculation is established.
- Retained the independent fitting-sample figure in the supplement and the
  independent forecast figures in the main article. The joint fitting-sample
  figure remains supplementary and the joint forecast figure remains in the
  main article.

### Validation figures

- Added `scripts/qdesn_evaluation_figure_style.R` as the shared statistical
  figure style and `scripts/render_qdesn_evaluation_figures.R` as the pure
  renderer from tracked result tables.
- Regenerated four active independent-validation figures and two active
  joint-validation figures as vector PDFs.
- Used family color, filled/open symbols for Q--DESN/DQLM or
  joint/independent structure, probability-level line type where applicable,
  and panel labels that remain interpretable in grayscale.
- Preserved free horizontal scales where the score magnitudes differ
  materially across data-generating mechanisms.
- Reported the five independent diagnostic warnings with daggers and the
  model-specific raw joint crossing counts in the joint forecast caption.
- Kept the two inactive independent VB forecast figures in the repository for
  reproducibility but removed them from the article-only publication list.

### Reproducibility contracts

- Updated the independent figure builder, finalizer, checker, and shell driver
  so that the active publication surface is generated by the shared vector
  renderer.
- Updated the joint projection checker and manifest for the regenerated joint
  figures.
- Updated the rolling-state and corrected-manuscript checks to the revised
  notation and active-figure boundary.
- Added `scripts/check_qdesn_final_manuscript_revision.R`, which verifies
  protected scientific hashes, score dimensions, crossing counts, manuscript
  placement, notation conventions, publication files, and abstract length.

## Interpretation

This commit is an editorial and graphical revision. The numerical conclusions,
model rankings, diagnostic warnings, forecast-crossing counts, and application
claims are unchanged. Any later scientific rerun or result promotion must enter
through its own frozen handoff and must rerun the protected-hash and manuscript
contract checks before publication.
