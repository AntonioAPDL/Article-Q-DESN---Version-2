Each criterion is recomputed for every retained conditional-quantile draw. Table entries report the posterior mean and equal-tailed 95\% credible interval of the resulting draw-wise criterion. The fitting-sample criterion is RMSE relative to the true conditional quantile path over 500 observations; forecast MAE and check loss aggregate the same 1,000 rolling-origin and horizon combinations used by the point comparison. These intervals condition on the simulated data set, evaluation grid, and criterion-specific fitted specification, including the selected reservoir realization. Repeated-simulation, model-selection, and reservoir-selection uncertainty are excluded. Variational Bayes intervals are approximate.

The model specification was selected separately for each criterion and simulation setting before the posterior interval analysis. Q--DESN and exQ--DESN intervals use conditional-quantile path draws; DQLM and exDQLM use latent-state quantile draws. The resulting intervals quantify posterior uncertainty in the aggregate criteria induced by each model's conditional-quantile summaries.

MCMC diagnostics were satisfactory for 104 of the 108 reported metric summaries; four summaries are marked with a dagger because at least one diagnostic warranted caution.
